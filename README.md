# 🤖 Telegram ИИ-Бот

Бот с искусственным интеллектом на базе **Google Gemini** (бесплатно!).

---

## 📋 Что умеет бот

| Команда | Описание |
|---------|----------|
| `/ask <вопрос>` | Задать вопрос ИИ |
| `/search <запрос>` | Поиск информации |
| `/send <id> <текст>` | Написать пользователю |
| `/clear` | Очистить историю диалога |
| `/help` | Справка |
| *любой текст* | ИИ ответит на сообщение |

---

## 🚀 Запуск за 5 минут

### Шаг 1: Создай бота в Telegram

1. Открой Telegram
2. Найди **@BotFather** (это официальный бот создания ботов)
3. Напиши `/newbot`
4. Придумай имя (например: `My AI Assistant`)
5. Придумай username (например: `my_ai_assistant_bot`)
6. **Скопируй токен** — он выглядит так: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

### Шаг 2: Получи бесплатный API-ключ Gemini

1. Открой https://aistudio.google.com/apikey
2. Войди в Google-аккаунт
3. Нажми **"Create API Key"**
4. **Скопируй ключ** — он выглядит так: `AIzaSy...`

### Шаг 3: Настрой проект

1. Установи Python 3.10+ с https://python.org
2. Открой терминал в этой папке и выполни:

```bash
pip install -r requirements.txt
```

3. Открой файл `bot.py` и вставь свои ключи:

```python
BOT_TOKEN = "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"  # токен от @BotFather
GEMINI_API_KEY = "AIzaSy..."                          # ключ от Google AI Studio
```

### Шаг 4: Запусти!

```bash
python bot.py
```

Увидишь `🚀 Запуск ИИ-бота...` — значит всё работает! 🎉

## ⚙️ Настройка

### Системный промпт (личность бота)

В файле `bot.py` найди `SYSTEM_PROMPT` и измени под себя:

```python
SYSTEM_PROMPT = """Ты — умный и дружелюбный помощник в Telegram.
Твоя задача — помогать людям с разными задачами...
"""
```

### Админ-команды

Чтобы команда `/send` была только у тебя:

1. Напиши **@userinfobot** в Telegram
2. Узнай свой ID (например: `123456789`)
3. Вставь в `bot.py`:

```python
ADMIN_ID = "123456789"
```

## ❓ Частые проблемы

**Бот не запускается**
→ Проверь, что вставил оба ключа в `bot.py`

**Ошибка "429 Too Many Requests"**
→ Бесплатный лимит Gemini исчерпан, подожди минуту

**Бот не отвечает**
→ Проверь, что токен бота правильный и бот запущен
