# Фронтенд для Netlify

## Как разместить на Netlify:

1. Зайди на https://netlify.com
2. Зарегистрируйся (бесплатно)
3. Перетащи папку `frontend` на главную страницу Netlify
4. Готово! Сайт доступен по ссылке

## Настройка:

1. Открой `index.html`
2. Найди строку: `https://t.me/YOUR_BOT_USERNAME`
3. Замени `YOUR_BOT_USERNAME` на username твоего бота
4. Загрузи обновлённый файл на Netlify

## Структура:

```
frontend/
├── index.html    — Главная страница
└── README.md     — Этот файл
```
